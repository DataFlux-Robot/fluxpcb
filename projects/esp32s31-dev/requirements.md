# esp32s31-dev — 树莓派Zero尺寸ESP32-S31开发板

单板,全公开文档(引脚全部来自官方数据手册,零编造):
- 65×30mm 2层,JLC工艺规则(3.5mil级)
- MOD1: ESP32-S31-WROOM-3U (99脚引脚表=Espressif官方datasheet Table 3-1;封装=espressif/kicad-libraries官方)
- USB-C(含USB_DP/DM原生USB 12Mbps + CC 5.1k×2), AP2112K-3.3 LDO(Diodes官方引脚),
  RESET/BOOT按键(KMR2), PWR/USER LED, 2×1x14 GPIO排针 + 1x4烧录排针, GND双面铺铜+缝合
