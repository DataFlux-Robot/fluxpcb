# research-ideation: 疯狂科学家多假设立题

## Why This Exists

Agent4Sci 实证: 无此 skill 的 agent 收益"几乎全部来自一袋工程技巧"，
坍缩为局部工程清扫。多假设+类别多样性是已验证的解药（10.4%→20.1%）。

## 核心纪律

1. **≥3 条假设，≥2 个假设类别**（重构问题/打破假设/换尺度/跨界类比）。
   单方案=单点故障。少于 3 条=不许开始实验。
2. **每条假设必须可证伪**："如果…会怎样"句式 + 判定实验（什么结果算
   支持/否定）。不可证伪的假设不是假设，是愿望。
3. **禁预设路线**：方案从证据（轨迹/诊断/文献）推导，不从"我们上次
   这么干"推导。
4. **研究喂入**：立题前检索文献/研究电池（research_battery.json），
   提案引用证据（"per dir8_escape_routing: …"）。跨界类比优先——
   其他领域已解的问题不要重新发明。

## 假设类别模板

| 类别 | 问法 | 本项目实例 |
|------|------|-----------|
| 重构问题 | 它真的是 X 问题吗？ | "口袋墙"其实是地图缺席 |
| 打破假设 | 哪些"不能动"其实可以动？ | 球位可以换（AF 表约束内） |
| 换尺度 | 整区推倒比局部修补便宜？ | 撤回-重划 vs 逐段 nudge |
| 跨界类比 | 其他领域怎么解？ | 证明助手的引理库 → 证书库 |

## Workflow

1. 收集证据: 读诊断/grind_state/失败档案 + research_battery + 检索。
2. 逐类别逼问（四类至少覆盖两类），每类产 1-2 条可证伪假设。
3. 每条附: 判定实验（A/B 怎么跑、什么算 PASS）、预期代价、风险。
4. 输出组合面（不是单选）: 假设可叠加验证。

## 反例（别这么干）

- "调 stall_penalty 试试" ×3 —— 这是拧旋钮，不是立题（53 微步 0 增益铁律）。
- 三条假设都是同一个机制的变体 —— 假多样性。
- 假设无法证伪："优化布线质量" —— 没有判定实验。
