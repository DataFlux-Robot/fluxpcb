# C — 测量、信用分配与自改进循环中“梯度”的正确性

综述日期 2026-11-25。30 次工具调用；只有 2411.00640 与 2610.09239 读过摘要以外的全文。
标 [记忆] 的为未重新获取的回忆；标“我们的推导”的算式是子智能体自己算的。
引用 2610.09239 的逐句数字前须对照 PDF 复核。

**要点**：最相关的是“The Winner's Curse in LLM Self-Improvement Loops”(arXiv 2610.09239)。
它在更大尺度上证实了我们的单次运行假阳性；它还发现更严的接受门并不优于贪心，
有效的修复是一个全新的审计集。归因方面，干预远胜于读轨迹的裁判。
对 23 块板，重复不能替代更多板。

## 1. 统计严谨性

- **Adding Error Bars to Evals** (Miller, 2411.00640)：单位是“题”。每题 K 次采样先对题内取均值，
  再在题均值间取标准误；把 K·N 个回答合并求 SE 是“不一致的”。重复只去掉题内方差项
  （其算例最多去掉三分之二）。功效公式 n = (z_α/2 + z_β)²(ω² + σ²_A/K_A + σ²_B/K_B)/δ²；
  ω²=1/9、δ=0.03、80% 功效时 n≈969。配对同一批题：相关 0.5 可去掉三分之一方差。
  聚类标准误可达朴素值的 3.05 倍。
- **Stochasticity in Agentic Evaluations** (2512.06710)：ICC 分解；GAIA 0.304–0.774；
  ICC 在 8–16 次试验后稳定，复杂推理需 32 次以上。
- **On Randomness in Agentic Evals** (2602.07150)：60,000 条轨迹；单次 pass@1 波动 2.2–6.0 个点；
  温度 0 时标准差仍 >1.5 个点。
- **Large Language Monkeys** (2407.21787)：覆盖率随采样数对数线性增长；无验证器时
  投票/奖励模型选择在几百次采样后饱和。**推理规模化重采样的极限** (2411.17501)：最优尝试次数
  常在 10 次以下。
- **The Coin Flip Judge** (2606.13685)：成对偏好在重复试验中平均 13.6% 翻转。

## 2. 噪声下的选择与赢家诅咒

- **The Winner's Curse in LLM Self-Improvement Loops** (Hu & Tang, 2610.09239)：
  模型在 keep-if-better 下改写自己的指令，每个候选同时在不用于选择的 600 题上打分。
  - 16 个选择项时贪心循环把留出准确率高估 **13–20 个点**；256 项时 1–5 个点。
  - 预言机运行：只有 **4–39%** 的改写胜过现任；真实留出效应均值 −0.2 到 −13.5 个点。
  - **更严的门在整个运行上没有胜过贪心**：McNemar α=0.05 在 TREC 上放弃了 7.4 和 12.3 个点
    的可得增益；门确实减少了有害提交（贪心 4/22，先导校准门 1/12，选后确认 0/10）。
  - **审计**：在 64 个从未用过的题上重评种子与现任（十分之一预算），去掉了平均偏差，
    RMSE 从 15.5 降到 5.7 个点。
  - GEPA 在 16 项上报告 TREC +38.8，真实 +19.2；Banking77 报告 +18.8，真实 1.2±1.7。
- **Prompt Optimization Is a Coin Flip** (2604.14585)：72 次运行中 49% 低于零样本。
- **SIREN** (2605.05973)、**SOTA or Luck?** (2611.22227)：选择与报告分离；重排修正 0.09–3.86 个点。

## 3. 信用分配

- **Who&When** (2505.00212)：最好 53.5% 智能体级、14.2% 步级。
- **因果推断归因** (Ma et al., 2509.08682)：在执行日志上反转数据流方向，Shapley 值分配责任，
  因果发现定位关键步骤；步级准确率最高 **36.2%**（此前 <15%）；生成的修复平均 +22.4% 任务成功，
  每个都用反事实模拟检验。
- **AgentDebug** (2509.25370)：+24% 全正确、+17% 步准确率。
- 结论：干预胜过观察——读轨迹的裁判约 14%，因果方法约 36%，且因果方法的修复可测量地有效。

## 4. 优化器改错东西

- **GEPA** (2507.19457)：比 GRPO 平均 +6%、最多 +20%，rollout 少 35 倍——基于每例结果的
  Pareto 前沿反思合并。但在 16 项的小验证集上同样高估。
- **TextGrad** (2406.07496)：GPQA 51%→55%。
- 奖励作弊的内部探针检测 (2609.19101)：某一模型 57.2%/73% 的运行存在作弊。
- 没有找到“反思式进化是否比文本梯度更常指对方向”的头对头检验。
  最接近的证据：第一代之后 61–96% 的改写是有害的。

## 5. 评测集构造

- **Efficient Benchmarking of AI Agents** (2603.23749)：只保留历史通过率在 **30%–70%** 的任务，
  8 个基准上任务量减少 44–70%。人人必过或必不过的任务不携带信息。
- **建立严格智能体基准的最佳实践** (2507.02825)：任务/结果有效性错误相对量可达 100%。
- 自改进中的污染：2610.09239（锁定效应）与 SIREN。
- “只能显示回退的留出集”：没有找到以此为题的论文；30–70% 过滤是最接近的。

## 6. 随机环境

- 2602.07150 与 2512.06710 是直接相关的两篇。没有找到关于非确定性路由器、PCB 自动布线
  或 KiCad DRC 作为智能体环境的论文。

## (a) 最强可用方法

1. **板块配对比较** (2411.00640)：同一批板、同一组种子上两臂各 R 次的每板通过率；
   在板层面给差值、标准误与区间。
2. **先做方差分解** (2512.06710)：对基线测每板 p 与 ICC，把噪声底作为界限报告。
3. **选后确认 + 全新审计层** (2610.09239, 2411.18569, 2605.05993)：开发板上贪心搜索；
   基线与候选各在从未用于选择的板上评一次。
4. **按基线通过率分层的留出** (2603.23749)：0<p<1 的板做双侧检验；必过的板做单侧护损。
5. **干预式的组件替换** (2509.08682, 2509.25370, 2606.08275)。
6. **竞速 / 最优臂识别** (2402.09723)。

## (b) 不可迁移

“至少 1000 题”与正态区间；把重复当样本量；面向跨模型排名的 coreset 工具；
排行榜修正；LLM 裁判做步骤归因；组件上的 Shapley；猴子式规模化；
GEPA/GRPO 的效率数字；在同一小集上用更严的门；把温度 0 当修复。

## (c) 可证伪的设计规则

**规则 1：没有噪声模型之前不做 A/B。** 基线每板至少 5 次重复（二元结果与分级结果都看）。
我们的推导：一块 p=0.2 的板被单对 A/A 暴露的概率只有 2p(1−p)=0.32，所以“23 块 0 翻转”
在这样一块板存在时仍有 68% 的概率出现；23 块 0 翻转给出的上界是每板翻转概率 12.2%
（1 − 0.05^(1/23)），而不是 0。R 次重复的检出率 1 − [p^(2R) + (1−p)^(2R)]：R=3 为 74%，R=5 为 89%。
单次比较在 p=0.2 的板上出现虚假获胜的概率是 p(1−p)=0.16。

**规则 2：板是单位；在板层面做配对检验并要求超过边际；更小的一律“未定”。**
MDE ≈ 2.8·√((ω² + 2σ²/R)/23)（80% 功效）：R=1 时 33.0，R=5 时 14.8，R=10 时 10.4（通过率点）。
只看符号：p<0.05 需要至少 6 个正向翻转且 0 个反向。

**规则 3：三层留出，在任何候选出现之前、只用基线数据固定。**
D 层：0<p<1 的板，双侧。G 层：必过的板，单侧护损（G 块 0 损失把损失率上界压到 3/G）。
F 层：全新板，只为最终报告评一次。
