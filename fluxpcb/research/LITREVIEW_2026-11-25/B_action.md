# B — 动作：固定模型下的工具 / skill / MCP 自进化

综述日期 2026-11-25。29 次只读联网调用。[V] 本次读过；[M] 对论文正文的回忆，未重新核实。

## 0. Hyperagents / DGM-H (arXiv:2603.19461) — 读了 v1 全文

- 设置：任务智能体与元智能体是围绕冻结模型（Claude 3.5/4.5 Sonnet）的**一个可编辑程序**。
- 起始提示：“修改 {repo_path} 下的任意部分”，外加 bash、编辑器工具、过往评估日志、剩余代数。
- 循环：从归档选父代 → 父代修改自己 → 评估子代 → 能编译就入归档。**没有分数阈值**。
- 选父代：权重 = sigmoid(10×(分数 − 前 3 均值)) × 1/(1+ 已编译子代数)，有放回采样。
- 分级评估：先小子集，其余记 0 分。
- Polyglot（80 代 × 5 次）：训练子集 0.140→0.340；全基准 0.084→0.267。
  原始 DGM：0.140→0.380 / 0.142→0.307（即编码任务上 DGM-H 并未超过 DGM）。
- 论文评审：0.0→0.710；手工定制的 DGM 0.590；原始 DGM 0.0。
- 机器人奖励设计：0.060→0.372；手工 DGM 0.348；原始 DGM 0.0。
- 消融（评审/机器人）：固定元智能体 0.0/0.213；无归档 0.0/0.116（均 p<0.05）。
  与手工定制 DGM 的差异不显著。
- 迁移：元智能体冻结、改进@50：手工 DGM 智能体 0.0；DGM-H 智能体 0.630。
- 叠加不显著；约 33M token/100 代（含评估约 88.6M）。
- **自改选父代规则未胜过手工规则**（0.491 vs 0.532）。
- **与我们最接近的观察**：初始机器人智能体常生成编译失败的奖励函数（引用了不存在的属性）。
  第 8 代它自己加了“合法属性文档”，消除了幻觉属性导致的失败；后来又加了
  “DO NOT reference env.torques ... THESE DO NOT EXIST”。
- **非编码任务上改善的是脚手架而非新工具**：输出解析、检查清单、决策规则、环境约束知识库、
  性能跟踪器、持久记忆。
- 未找到独立复现或批评。

## 1. LLM 造工具

- **LATM** (2305.17126)：GPT-4 造工具、GPT-3.5 用，复杂推理上追平 GPT-4 且成本更低。
- **CRAFT** (2309.17428)：解训练样例 → 验证 → 抽象成工具 → 去重 → 推理时检索。
- **TroVE** (2401.12869)：use-grow-prune，工具箱小 79–98%。
  **重新评估** (2507.22069)：算力匹配后相对直接生成的增益缩到约 1%。
- **Alita** (2505.20286)：自生成 MCP 工具；GAIA 验证 pass@1 75.15%、pass@3 87.27%。
- **Alita-G** (2510.23601)：**只从成功运行保留工具**，再做抽象（参数泛化、FastMCP 接口、文档）。
  GAIA 验证 pass@1 75.15% → 80.00%（1 次迭代）→ 83.03%（3 次）；13 题错转对、**0 题对转错**；
  每例 token 12,305 → 10,394；第 3 次迭代饱和。
- **SkillWeaver** (2504.07079)：提出技能 → 执行练习 → 精炼 → 存为 API；WebArena +31.8%（相对），
  真实网站 +39.8%；强智能体的 API 可把弱智能体提升最多 54.3%。
- **Live-SWE-agent** (2511.13646)：bash-only 智能体写自己的脚本，**没有任何验证门**；
  SWE-bench Verified 77.4% vs 74.2%；50 题上 62.0%（无造工具）→ 76.0%（完整）。
  **弱模型被伤害**：GPT-5-Nano 44.0% → 14.0%。
- **Voyager** (2305.16291)：技能库，LLM 自验证后入库（非确定性）。

## 2. 自改进智能体

- **DGM** (2505.22954)：SWE-bench 20.0%→50.0%；幻觉工具调用是其观察到的失败模式。
- **SICA** (2504.15228)：17%→53%。
- **Huxley-Gödel Machine** (2510.21614)：基准分数不能预测好的后代；按后代总体表现选父代。
- **Gödel Agent** (2410.04444)：MGSM 64.2 vs 53.4；100 次试验中 92% 出现暂时下降、
  14% 低于初始策略、4% 异常终止。
- **Aspire** (2608.31111)：从模糊目标进化，最好的 harness 低于工程参考；继续搜索会抹掉早先增益。

## 3. 生成代码的 API 接地

- **DAG** (2407.09726)：GPT-4o 对低频 API 的合法调用率仅 **38.58%**；文档检索升到 47.94%。
- **幻觉率** (2604.07755)：8.1–40% 的响应调用不存在的库特性；静态分析能抓到 **14–85%**。
- **LibHalluBench** (2509.22202)：一个字符的拼写错误在最多 26% 的任务里触发幻觉。
- **DocPrompting** (2207.05987)：先生成再检索文档；CoNaLa +2.85% pass@1。
- **类型约束解码** (2504.09246)：编译错误减半——需要 logit 访问，不可迁移。
- **Self-repair 研究** (2306.09896)：算上修复成本后增益不大；瓶颈是读反馈。
- **Tool-Genesis** (2603.05578)：接口合规、功能正确、下游效用分开打分；顶级模型也无法一次
  给出精确接口。

## 4. 库的准入与退休

- **Ratchet** (2605.22148)：**LLM 写的技能值 +0.0pp**（人写的 +16.2pp）；无维护的库会漂移到
  “注入不如不注入”。按测得贡献驱逐：困难切片留出 pass@1 +0.328。
- **ASSAY** (2606.15390)：逐技能因果效应（随机掩蔽），再按任务类型抑制；
  AppWorld 最难划分 69.3%。
- **TRUST** (2611.10787)：在线多重假设检验门；被接受的劣质更新从 45.59%（贪心）降到 **2.78%**。
- **SkillSpec** (2610.00704)：只有配对评估在每次重复中都是非负增益才提交。
- **技能退休研究** (2610.32322)：基于增益的退休不可靠，需要有效性门。
- **Memp** (2508.06433)、**ACE** (2510.04618)：带更新/弃用机制的程序性记忆。

## 5. MCP 时代

- **BioinfoMCP** (2510.02139)：LLM 生成的 MCP 服务，38 个工具 94.7% 正确执行。

## 6. 非编码领域

支持：DGM-H 评审与机器人；SkillWeaver；Alita-G；HandRSI (2611.22164)。
反对：与手工定制 DGM 统计上不可区分，增益来自脚手架与文档而非新工具；Gödel Agent 不稳定；
物理 AI 综述 (2610.29677) 没有找到分离“递归归因增益”的研究。

## (a) 最强可用方法（冻结模型、沙箱写工具、固定原语 API）

1. **契约包 + 确定性名字门**——正好修我们的失败。证据：DGM-H 第 8 代；DAG 38.58→47.94%；
   静态分析抓 14–85%。
2. **版本化归档 + 编译门控准入 + 分级评估 + 子代数惩罚的选父代**（DGM-H、Huxley-GM）。
3. **只从验证成功的运行收割工具，再抽象，按描述检索**（Alita-G）。
4. **统计准入门 + 按测得贡献退休**（TRUST、SkillSpec、Ratchet、ASSAY）。
5. 轨迹内造工具 + 反思提示（Live-SWE-agent）——便宜但依赖模型。
6. 持久失败记忆 + 性能跟踪器——DGM-H 自己发明了这两样；直接给比进化出来便宜。

## (b) 不可迁移

需训练权重的；解码级约束；整程序自改作为默认（约 33M token/100 代，不稳定，非编码域被
手工元智能体追平）；“分数更高就留”的贪心（TRUST：45.59% 被接受的更新是劣质的）；
靠额外算力成立的工具库；LLM 判定的准入；弱基座模型上的无门造工具。

## (c) 可证伪的设计规则

1. **内省契约包，然后静态门**：从真实模块内省签名/文档/返回类型，每个原语一个可运行例子，
   明确“只有这些符号存在”。进沙箱前用 AST 对照检查每个导入名与属性；失败则返回出错符号
   和最近合法名，给一轮修复。预测：第 2 轮名字合法率 ≥90%，运行时零 AttributeError/ImportError。
2. **归档而非覆盖；准入需三道门**：静态门；3–5 块板上的探针运行返回类型化状态；
   与当前最优的配对差值（≥2 次重复，每次非负）。保留所有版本，按
   sigmoid(分数)×1/(1+子代数) 选择，先评便宜的板。
3. **工具声明前置条件、返回类型化失败、按测得贡献退休**：每个工具返回
   ok / precondition_failed / infeasible / error；precondition_failed 路由到升级工具
   （多网撕开或网序）而不是重试；每 K 轮在小开发集上掩蔽各工具，贡献不高于驱逐边际则退休或限定范围。
