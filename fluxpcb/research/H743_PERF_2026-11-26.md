# H743 飞控：复杂场景性能实测（2026-11-26）

用 `flux run` 在 H743 飞控上跑完整六阶段，测复杂场景的性能与收敛性。板子是
`projects/h743-fc`：STM32H743XI TFBGA240、8 路 PWM、8 路 UART、SD、双 IMU/双
气压计/磁力计、2 路 CAN、USB-C、SWD（50×50 mm，6 层，33 个封装，75 网）。

跑的是**副本** `z_lab/fp/h743_run`（原项目未动，快照在 `z_lab/fp/h743_before`）。

## 二、结果状态

板子（最终提交态）：50×50 mm、33 封装、75 网、439 段走线、106 孔、6 个铺铜区。

- **43 条未连接**（ratsnest），0 短路；`loop_final`：iterations=3，最后动作 direct_link。
- **17 条 DRC**：
  - `annular_width` 4（实际 0.075 < 0.100）
  - `drill_out_of_range` 4（0.15 < 0.20）
  - `via_diameter` 4（0.30 < 0.40）
  - `clearance` 3（0.108–0.146 < 0.150）
  - `holes_co_located` 2
- 孔尺寸分布：0.6/0.25 ×73、0.5/0.25 ×15、0.4/0.2 ×10、0.6/0.3 ×4、**0.3/0.15 ×4**。
  那 4 个 0.3/0.15 正好贡献了上面 12 条规则违规，来源是 `power_stitch` 的最小档
  （见第四节）。

## 三、与 2026-11-22 独立布线对比

| | 11-22 独立 `bench_runner`（p4） | 本轮 `flux run` 的 auto_route |
|---|---|---|
| 墙钟 | **951.6 s（15.9 min）** | **54 min**（含 2 趟 Freerouting） |
| 走线/孔 | 581 段 / 74 孔 | 439 段 / 106 孔 |
| 未连接 | **0** | **43** |
| DRC | 9（clearance） | 17（含 4 个非法过孔） |

结论：在这块 264 球 BGA 板上，**独立 Freerouting 路径比流水线内的 auto_route
快 3.4 倍且闭合了全部开路**；流水线路径把 A* 的中间结果回滚后，靠两趟
opens-only Freerouting 收尾，仍未闭合。

## 四、这轮实测抓到并修掉的两个缺陷

1. **门禁与布线阶段把上一轮备份当输入**：`pcb/` 下有 `*_p4_routed`、`placed`、
   `unrouted`、panel 等历史产物，而 6 个门和 `pcb_layout` 都用
   `rglob("*.kicad_pcb")`。后果：`routing_completeness` 报"4 块板未全连通"、
   `fabrication_netlist` 报"4 块板网表不符"、`plane_integrity` 误报 12 层无铜
   （真实板 PASS），且布线阶段会把 4 块板各布一遍（约 4× 墙钟）。
   修法：新增 `fluxpcb/board_files.py`（`gate_boards` / `canonical`），6 个门与
   `pcb_layout` 统一使用；修正后同一块板：DRC 17（原 26）、"1 块板"、
   plane PASS。
2. **电源缝合的过孔下限低于板自己的规则**：`power_stitch` 的
   `VIA_SIZES` 最小档是 0.3/0.15（JLC 工艺极限），而这块板的规则是
   0.4/0.2、环形 0.1 → 4 个孔 ×3 类 = 12 条 DRC。修法：`stitch_params.py`
   把下限收到 0.4/0.2（放不下就跳过，非法过孔不算缝合），并加测试。
   注：本轮测量在修复之前，重跑时这 12 条会消失；43 条开路仍在。

## 五、没修的、留给下一轮

- **43 条开路**：A* 阶段能到 1772 段（更接近闭合），但事务门回滚后 FR 收尾只到
  439 段。需要看回滚判据（shorts/opens 加权）在 BGA 上的取舍，或者让 A* 的结果
  进入 FR 的 fixed 集而不是被丢掉。
- **重试放大**：门禁失败会重跑整个 `pcb_layout`（54 min ×3 ≈ 2.7 h），而每轮都是
  从头再布，不收敛。真实产品需要对"路由未收敛"区分可重试/不可重试。
- **网表 74 vs 75**：板多一个网（可能是 FR 导入产生的孤立 net），要查
  `fabrication_netlist` 的差集输出。
- `impedance_si` 仍要求声明阻抗目标（H7 有 USB/SPI，应补）。

```bash
python -m fluxpcb.bench_runner <board.kicad_pcb> <out.kicad_pcb> --timeout 1200
```
